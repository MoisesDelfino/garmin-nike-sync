Conectar Nike Run Club

Processo super simples em 3 passos

1
Adicione o Botão Mágico

👇 ARRASTE ESTE BOTÃO PARA OS FAVORITOS 👇

⚡ CONECTAR NIKE ⚡

Clique, segure e arraste para a barra de favoritos

Como fazer:
  1. Clique no botão "⚡ CONECTAR NIKE ⚡" e segure
  2. Arraste o mouse até a barra de favoritos (no topo do navegador)
  3. Solte o botão do mouse

💡 Não consegue ver a barra de favoritos? Pressione Ctrl+Shift+B (Windows/Linux) ou Cmd+Shift+B (Mac)

2
Faça Login no Nike.com

Agora clique aqui para abrir o Nike.com e fazer login:

ABRIR NIKE.COM E FAZER LOGIN
Importante: Use o mesmo email e senha da sua conta Nike Run Club
3
Clique no Botão Mágico
Agora é só clicar!

Procure na barra de favoritos (no topo do navegador) pelo botão:

⚡ CONECTAR NIKE ⚡

Clique nele na aba do Nike.com e pronto! A conexão será feita automaticamente e você será redirecionado para o dashboard.

Aguardando você clicar no favorito...

Esta página detectará automaticamente quando a conexão for feita

Como funciona?

O botão que você arrasta é um bookmarklet (favorito com código JavaScript). Quando você clica nele estando logado no Nike.com, ele extrai automaticamente seu token de acesso e envia para nosso servidor de forma segura.

100% seguro: O código roda apenas no seu navegador e não compartilha nenhuma informação além do token de autenticação.
